# Homebrew tap for `qsp`

The [QuickSilver Pro CLI](https://github.com/machinefi/qspro-cli) on Homebrew.

```bash
brew install machinefi/qspro/qspro
qsp init
qsp chat "Hello"
```

`qsp` is an OpenAI-compatible command-line client for [QuickSilver Pro](https://quicksilverpro.io), an inference API for DeepSeek V3, DeepSeek R1, and Qwen 3.5 priced 20% below OpenRouter / Together / Fireworks.

The formula is auto-bumped by [this workflow](https://github.com/machinefi/qspro-cli/blob/main/.github/workflows/publish.yml) on every CLI release.
